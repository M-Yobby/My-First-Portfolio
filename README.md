Meshack Yobby Portfolio

A clean and responsive personal portfolio website showcasing my background, skills, projects, and contact information. Built using HTML5 and CSS3, this portfolio serves as a hub to present my professional profile and achievements.



📖 Project Overview

This project is a personal portfolio website designed to:

* Introduce who I am and what I do
* Highlight my skills, education, and professional interests
* Showcase my projects and career achievements
* Provide a simple way to contact me
* Include a downloadable CV for potential employers



The website is structured for clarity, simplicity, and easy navigation, making it ideal for showcasing my work to recruiters, collaborators, or anyone interested in my journey.



🛠️ Features

1\. Header Section

Displays my name, tagline, and profile image.

Styled with a green background block for emphasis.

Uses Flexbox to align the text and image neatly.



2\. About Me

A brief introduction about my journey into tech.

Written in a friendly and professional tone.



3\. Educational Background

Lists my academic qualifications and training.

Provides a downloadable CV in PDF format.



4\. Interests

Highlights my passions and hobbies, including tech, film, music, writing, and tea culture.

Includes a clickable link to my published book: "Once, There Was A Star"



5\. Projects

Showcases my projects with brief descriptions and direct links, including:
Python Calculator App (GitHub link)
Portfolio Website (GitHub link)
Film Production Project (YouTube link)
Color Quiz App (GitHub link)
Greeting App (GitHub link)
Joke Generator (GitHub link)
My First Portfolio (GitHub link)


6\. Contact Section

A simple call-to-action inviting collaboration.

Direct Gmail compose link for easy contact.

Styled with centered text and link.



7\. Footer

Displays copyright information.

Styled with a dark background and centered white text.



8\. Section Separators

Elegant white horizontal lines separate sections.

Lines are limited to the paragraph width, creating a professional, column-like feel.



💻 Technologies Used

HTML5 – For the structure of the website

CSS3 – For styling and layout

Responsive Design Techniques – Ensuring it looks clean on mobile and desktop
